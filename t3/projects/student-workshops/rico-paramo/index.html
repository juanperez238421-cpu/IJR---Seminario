CLASS 2 · ENGINE

Frame-rate-independent procedural engine

NOT COMPLETE

Move from “pixels per frame” to state updated from elapsed time. The scene must behave approximately the same at different render frequencies.

Core rule

dt = clock.tick(fps) / 1000.0
x += speed_px_s * dt

Simulation state changes in units per second, not a fixed amount per frame.

Test

  • Run at 30 FPS.
  • Run at 120 FPS.
  • Compare motion duration over the same interval.
  • Record the observed difference.
GATE 03Motion timing remains approximately consistent across the FPS comparison.

CLASS 3 · PACKAGE

Portable build + visible manual launcher

NOT COMPLETE

Package the working application, then prove portability from a clean destination. A successful build command alone is not evidence.

PORTABLE_BUILD/ ├─ PortableVisualShow.exe ├─ config.json ├─ launch.bat ├─ assets/ └─ README.txt

Package

pip install pyinstaller==6.16.0
pyinstaller --noconfirm --clean --onefile --name PortableVisualShow main.py

Launcher contract

The launcher is explicit, visible and user-initiated. It starts the packaged program and does not modify system startup or persistence settings.
